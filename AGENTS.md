# Repository workflow

- Develop on a named feature branch. Never push development changes directly to `main`.
- Do not merge a feature branch or pull request without the user's explicit request.
- Use the user's GitHub account and configured Git identity. This checkout uses September62 and Henry Hird; never substitute a ChatGPT/OpenAI author or add an AI co-author.
- Keep `.env` and other private configuration out of Git and deployment archives. `.env.example` contains placeholders only.
- Campus membership and geometry must have cited sources. Keep shared occupation, unknown locations and estimated heights explicit; never invent footprints to fill coverage gaps.
